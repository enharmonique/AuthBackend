# AuthBackend

**AuthBackend** is a robust and secure backend API service built with **Java** and **Spring Boot**, designed to handle
user authentication, data management. Leveraging **JWT (JSON Web Token)** for authentication and **Spring Security**,
this backend ensures secure and efficient communication between the client and the server.

---

## Features

- **User Registration and Authentication**: Secure user sign-up and login using JWT.
- **Protected Endpoints**: Access to sensitive endpoints is restricted to authenticated users.
- **Database Persistence**: Data is persisted using either a in-memory H2 database
- **HTTPS Support**: Secure communication between clients and server via HTTPS.
- **Input Validation**: Ensures data integrity and security through server-side validation.

---

## Technologies Used

- **Java**
- **Spring Boot**
- **Gradle**
- **Spring Security**
- **JWT (Java JWT)**
- **H2 Database**
- **Lombok**
- **Keytool** *(for SSL certificate generation)*
